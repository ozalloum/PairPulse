# PairPulse submission package v0.2.1

This archive contains the revised manuscript PDF and LaTeX source, six figure PDFs and PNGs, Python source, regression tests, reproduction scripts, and an unexecuted notebook.

Numerical validation records, CSV datasets, run metadata, executed notebooks, and execution logs are excluded. The README explains how to generate fresh results with the included scripts.

Public release: https://github.com/ozalloum/PairPulse/releases/tag/v0.2.1

Verify the distributed files with `python scripts/verify_checksums.py`. The external SHA256SUMS file checks the ZIP and manuscript PDF. Journal submission remains an author action.
