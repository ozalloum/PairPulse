# Before a CPC submission

This is a complete working manuscript and reproducibility package, not a claim of guaranteed acceptance.

The physics problem is distinct from spherical electrostatics: it evolves time-dependent Dirac and quantum-kinetic momentum modes in an electric pulse. It does not use a Green-function/Legendre-series solution.

- The manuscript uses the CAS double-column format and the author name, email, ORCID, and affiliation from the supplied reference manuscript. The matching CAS class and support style are bundled with their upstream notice.
- The bibliography contains 30 DOI-linked works spanning the foundational Schwinger literature, kinetic and Dirac-mode formulations, pulse interference, and spatial-field limitations.
- Create a public, versioned software archive and insert its persistent identifier and repository link in the program summary and availability statement. The supplied source is MIT licensed.
- Check the current CPC Computer Programs in Physics criteria and program-library deposit requirements before submission.
- The calculations use established Dirac-mode and quantum-kinetic formulations. The manuscript's contribution is the paired, validated reference implementation and reproducible output, not a new physical mechanism. Existing literature already treats pulse-driven pair creation and exact Sauter-field solutions, so claims of novelty stay limited to the software package and its tested scope.
- The included physics validation is intentionally narrow: one spatial dimension, a prescribed homogeneous field, Sauter pulse(s), and no back-reaction. A referee may ask for broader capability or stronger evidence that the program is significant enough for a CPiP article.
- Before submission, have a domain expert check the theory conventions and assess whether the software's scope and documentation meet CPC's threshold. Review the AI-use disclosure and the final manuscript.

The source, tests, notebook, generated figures, numerical tables, environment metadata, and manuscript build files are in this package so that these decisions can be made against a concrete artifact. The figure set includes Python-generated public-package and computational-workflow diagrams, plus an absolute finite-window error map over canonical momentum and Sauter-pulse tail extent. The error-map values are generated by fresh integrations and exported as a CSV; this homogeneous-field model has no spatial error coordinate.
